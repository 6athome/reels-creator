# 문제 해결

- **입력 폴더를 찾을 수 없음** — Git 저장소 밖의 로컬 작업 공간 경로를 Codex에 알려주고, 작업 공간의 `input`에 사용할 영상이나 사진이 있는지 확인하세요. 경로에 공백이나 한글이 있어도 됩니다.
- **기획안만 보이고 영상이 없음** — 기획안 확인을 먼저 요청했다면 Codex가 승인을 기다리는 중일 수 있습니다. 이대로 진행하려면 “이 기획안대로 만들어줘”라고 답하세요.
- **어떤 영상이 최신인지 헷갈림** — 같은 대화에서 최신 영상과 표지 링크를 요청하세요. 수정 전 파일도 이전 버전 폴더에 남습니다.

- **명령이 없거나 실행되지 않음** — 설치 폴더에서 `doctor.py`를 실행하고 안내된 공식 배포처에서 누락된 도구를 준비하세요. Windows는 `py -3`, macOS는 `python3`로 실행합니다. 도구 설치와 PATH 변경은 사용자의 승인 후 진행합니다.
- **Chromium을 찾을 수 없음** — 기존 호환 브라우저 경로를 렌더 명령의 `--browser`로 넘기거나, 다운로드를 승인한 후 설치 스크립트의 브라우저 옵션을 실행하세요. 백신·샌드박스가 실행을 제한하면 실행 로그를 확인하고 Codex의 정상 승인 절차를 사용합니다.
- **스킬이 표시되지 않음** — 설치 경로가 `~/.agents/skills/reels-creator/SKILL.md`인지 확인하고 Codex를 다시 로드하거나 재시작하세요. 다른 `--skills-dir`은 해당 경로가 Codex 검색 대상일 때만 자동 인식됩니다.
- **설치 경로에 기존 파일이 있음** — 설치 스크립트는 기존 파일을 보존합니다. 작동 중인 설치의 업그레이드는 기존 설정을 백업하고 별도 경로에서 검증하세요.
- **한글이 네모로 보임** — 시스템 한글 글꼴을 확인하고, 필요하면 사용 권한이 있는 파일을 로컬 등록하세요. [실행 가이드](local-engine.md)
- **컷 시간이 원본을 넘음** — 표시된 마지막 안전 구간 이하로 `sourceEnd`를 줄이고 컷 길이, 이후 컷·자막 프레임 및 전체 시간을 맞추세요.
- **MP4 또는 PNG가 없음** — 콘솔의 마지막 단계와 버전 폴더의 `render-report.json`을 확인하세요. 검토 모드는 계획까지만 만들고, 표지 전용 모드는 PNG를 생성합니다.
